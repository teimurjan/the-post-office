Agents that skipped the skill file wrote better code.

Dan Luu tested 26 ways of telling a coding agent to test its own work, implementing Zstd compression in Rust, 80 runs each. On one popular Rust testing skill, the agents that never opened it scored well. The ones that engaged with it closely scored poorly.

Tell an agent to do TDD and you get twice as many tests and lower correctness. Giving it no testing instructions at all landed above average.

I keep a repo of my own skills, mostly for marketing and for connecting to services. The service part I hand to MCPs now when I can. With new models and new harnesses, skills matter less than they did.

Keep them, just not as thousand-line instructions. The smarter the agent gets, the dumber the skill becomes.
