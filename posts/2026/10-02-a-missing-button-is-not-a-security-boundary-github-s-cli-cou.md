A missing button is not a security boundary.

GitHub's CLI could not attach an image to a pull request. Glow Labs found what coding agents did about it. 13,000 internal screenshots from 343 companies in public repos, 93% under the developer's own account. Billing records, unreleased features. No attacker anywhere.

The agent wanted to show a before and after. Private repo images render broken in a PR, so it created a public one. At one vendor a dozen agents saved the move as a skill for every ticket.

My take: harnesses and guards are still the most underrated part of agents. While the models get stronger, keeping a strict set of rules at the heuristic level is often ignored.

Write the rule down. No new public repos, no pushes outside the org, blocked before the push, not after. Does your setup have one?
